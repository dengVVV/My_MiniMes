# My_MiniMes- 简易MES管理系统

一个基于C#、WPF和MVVM架构的轻量级制造执行系统（MES）。SimpleMES支持实时设备监控、订单管理、生产追踪，以及通过Modbus协议与TCP和RTU串口设备通信。

## 什么是SimpleMES

SimpleMES是一个专为中小型制造企业设计的生产管理系统。它提供工业设备的实时监控、订单下达与追踪、生产记录管理，以及数据可视化报表。系统通过Modbus协议与设备进行TCP或RTU串口通信，采集温度、压力、速度等传感器数据。

### 技术栈
- **语言:** C# (.NET 6.0)
- **框架/运行时:** WPF (Windows Presentation Foundation)、.NET 6.0 Windows
- **UI架构:** MVVM (Model-View-ViewModel) + Community Toolkit MVVM
- **数据库:** SQLLite + EF Core + Dapper ORM
- **主要依赖库:**
  - **NModbus** (v3.0.81) — Modbus协议实现，支持TCP和RTU串口通信
  - **LiveChartsCore.SkiaSharpView.WPF** (v2.0.0-rc2) — 实时数据可视化和图表展示
  - **MaterialDesignThemes** (v4.9.0) — Material Design现代UI组件
  - **Serilog** (v4.3.1) — 结构化日志系统，支持文件、Debug和异步输出
  - **CommunityToolkit.Mvvm** (v8.3.2) — MVVM工具库和可观测属性绑定

**工作流程：**

1. **应用启动(App.xaml.cs):** 初始化Serilog日志、SQL Server连接和所有服务。创建并启动`DeviceCommunicationService`作为后台服务（MES的心脏）。

2. **设备通信循环:** `DeviceCommunicationService`为每个配置的设备维护独立轮询循环。每个循环周期：
   - 复用或创建长连接(TCP或RTU Modbus)
   - 调用轮询策略采集数据(温度、压力、速度)
   - 通过`DataRepository`持久化到SQL Server
   - 使用状态机追踪设备状态(连接/断连)
   - 通知UI设备状态变更

3. **UI数据绑定:** ViewModel订阅设备状态变更事件，更新ObservableCollection。WPF数据绑定自动推送更新到LiveCharts进行实时可视化。

4. **数据持久化:** 所有设备读数、订单和生产记录通过`DataRepository`(基于Dapper的SQL Server访问)进行存储。

## 快速开始

### 系统要求
- **操作系统:** Windows (WPF桌面应用)
- **.NET版本:** .NET 6.0 SDK及以上
- **数据库:** SQL Server (本地或远程实例)
- **开发工具:** Visual Studio 2022或更高版本(推荐) 或其他C#开发工具

### 安装步骤

登录系统:

使用SQL脚本中创建的默认用户凭证登录
成功认证后进入主仪表板
主要入口点
应用启动: App.xaml.cs → 依赖注入和服务初始化
主UI: MainWindow.xaml → 显示监控、订单、报表三个标签页面
设备管理: 通过UI对话框添加/编辑设备，自动启停轮询任务
配置说明
设备轮询间隔: 默认2000ms，可在 DeviceCommunicationService.SingleDevicePollingLoop 中修改
Modbus通信: 支持TCP(可配置端口)或RTU(可配置串口)，在添加设备时设置
日志输出: 由 Helpers/Log/ 配置(通过Serilog写入应用目录)
常见问题
设备Modbus连接如何保持长连接？
查看 Core/DeviceCommunicationService.cs 第102行 — _activeClients 并发字典复用设备客户端连接，每个轮询周期重用同一连接，避免频繁重连。

实时设备仪表板的数据从何而来？
MonitorViewModel.cs 订阅 DeviceCommunicationService.DeviceStatusChanged 事件，将设备快照绑定到 LiveChartsCore 进行温度/压力/速度趋势渲染。

订单如何下达到设备，生产进度如何追踪？
OrderViewModel.cs 和 Services/Orders/ 目录处理订单创建和状态转换。生产记录插入SQL Server，由 ReportViewModel.cs 查询用于历史报表统计。
